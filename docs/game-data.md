# Game Data Reference

本文档记录当前代码里的植物、元素、怪物基础数据。

## 通用公式

| 项目 | 规则 |
| --- | --- |
| 植物伤害升级 | 每级 +5%，即 `baseDamage * (1 + 0.05 * (level - 1))` |
| 植物射程升级 | 每级 +1%，即 `baseRange * (1 + 0.01 * (level - 1))` |
| 植物攻速升级 | 每级 +2%，攻速为 0 的植物仍为 0 |
| 灰烬/一次性植物升级 | 默认只看伤害升级；不支持元素升级；范围、延迟、控制时间不随等级提升 |
| 植物/元素升级碎片 | `5 + 5 * (currentLevel - 1)` |
| 植物/元素升级金币 | `100 * currentLevel` |
| 怪物生命等级倍率 | `baseHp * (1 + 0.1 * (monsterLevel - 1))`，所以 level 1 等于基础数据 |
| 怪物护甲等级倍率 | `baseArmorHp * (1 + 0.1 * (monsterLevel - 1))`，仅拥有护甲的怪物生效 |
| 怪物速度 | 当前使用基础速度，不随等级自动提升 |
| 波次间隔 | 默认每波结束后 2 秒开始下一波 |
| 同波怪组时序 | 怪组 `startDelay` 留空时按顺序刷，同组间默认间隔 2 秒；填写 `startDelay` 后按本波开始后的秒数调度，同一秒数会同时刷；同一波只填部分怪组时，未填的怪组继续按前面怪组结束后的顺序自动排 |
| 孤注一掷击杀奖励 | `lastStand.killReward` 控制该模式所有怪物（包括 Boss）的统一击杀阳光，默认 0；不影响其他模式 |
| 传送带植物/元素等级 | 已解锁时沿用账号等级，未解锁时临时按 `max(1, floor(当前难度定数 / 2))` 使用，例如 AT17 按 8 级；南瓜头没有等级；实验室继续使用自定义测试等级 |
| 打地鼠出生规则 | 每只怪物随机选择一条路径，并随机出现在该路径前 80% 的位置；Boss 使用相同规则 |
| 打地鼠强制植物 | 关卡配置 `whackAMole.plants` 决定可用植物；玩家已解锁时使用自己的等级，未解锁时临时按 1 级使用；元素仍读取玩家已解锁内容 |
| 打地鼠锤子 | 1 级默认伤害 30，可由 `whackAMole.hammerBaseDamage` 调整；每级伤害 +20；升级费用为 `200 + 100 * (hammerLevel - 1)` 阳光 |
| Boss 体型 | 只有怪组勾选 `isBoss` 时才使用固定的大体型渲染；普通怪不随血量变大 |
| Boss 击杀奖励 | 固定 497 阳光，不读取波次配置；孤注一掷的统一奖励设置优先 |
| 真实护甲 | 未破甲时优先扣护甲，护甲扣完后溢出伤害扣本体；破甲状态下伤害绕过护甲直接扣本体 |
| 无护甲破甲 | 没有护甲条的怪物处于金元素破甲状态时，会受到额外伤害倍率 |
| 冻结与减速 | 冻结单独记录；冻结期间速度为 0，冻结结束后仍可继续保留普通减速 |

## 宝箱碎片

- 所有品质宝箱使用同一个碎片池：全部可升级植物 + 全部元素，每次抽取每种碎片概率完全相同，不受解锁状态影响。
- 当前共有 23 种植物、6 种元素，每种碎片每次抽取概率为 `1 / 29`（约 3.45%）；南瓜头没有等级，不掉碎片。
- 每次独立抽取，可以重复；等概率不代表每个宝箱都会开出相同种类或数量。宝箱品质仍决定原有的碎片总数、金币等奖励。

| 项目 | 当前规则 |
| --- | --- |
| 初始田地 | 8 块 |
| 田地扩建 | 每次增加 1 块，费用 2000 金币；当前没有额外上限 |
| 植物种子成熟时间 | 基础 2 小时 |
| 宝箱种子成熟时间 | 基础 6 小时 |
| 离线成长 | 成熟时间按服务器时间计算，玩家不在线也会继续倒计时 |
| 植物种子种植 | 种下时从所有可升级植物中随机确定目标植物；南瓜头不在候选池内 |
| 一键种植 | 仅使用当前选择的植物种子或宝箱种子，按田地顺序填满已解锁空地；种子不足时种完现有数量，不覆盖作物、不自动解锁田地 |
| 植物种子收获 | 获得目标植物碎片；碎片数量由时运决定，并独立判定是否回收 1 个植物种子 |
| 宝箱种子收获 | 获得 1 个宝箱；不会回收宝箱种子 |
| 宝箱库存限制 | 最多 20 个宝箱；库存满时不能收获宝箱种子 |

### 花园升级

两个升级都消耗经验，升级费用为 `3 + 当前等级` 经验，初始等级均为 1。

| 升级 | 等级上限 | 效果 |
| --- | ---: | --- |
| 效率 | 80 | 每级使种子成熟时间相对基础时间减少 1%；等级 1 不减少，等级 80 为基础时间的 21% |
| 时运 | 50 | 提高植物碎片数量和植物种子回收率；碎片数量概率最多按 11 级计算 |

时运等级按 `luckSteps = min(时运等级, 11) - 1` 计算植物碎片数量：

| 碎片数量 | 概率 |
| ---: | ---: |
| 1 个 | `100% - 10% * luckSteps` |
| 2 个 | `7% * luckSteps` |
| 3 个 | `3% * luckSteps` |

植物种子回收率为 `49% + 当前时运等级`，最高等级 50 时为 99%；每次最多回收 1 个植物种子。

### 宝箱种子收获概率

每个宝箱种子固定获得 1 个宝箱，概率独立于植物种子碎片规则：

| 宝箱类型 | 概率 |
| --- | ---: |
| 普通宝箱 | 80% |
| 稀有宝箱 | 15% |
| 史诗宝箱 | 4% |
| 传奇宝箱 | 1% |

### 宝箱种子来源

打开宝箱时，植物种子和宝箱种子分别独立判定：

| 来源宝箱 | 植物种子 | 宝箱种子 |
| --- | ---: | ---: |
| 普通 | 20%，1 个 | 20%，1 个 |
| 稀有 | 50%，1 个 | 50%，1 个 |
| 史诗 | 80%，1 个 | 80%，1 个 |
| 传奇 | 100%，3–5 个 | 100%，3–5 个 |

### 趣味模式：无尽模式

- 开局选择已解锁卡组，最多 10 株植物、3 种元素，等级沿用账号；初始阳光 500、生命 15。
- 随机选择地图，排除训练回环；慈善大使出现概率 2%，击杀恢复 1 生命，最多恢复至 15。
- 每波 50 只怪物，首波等待 10 秒，每只间隔 0.4 秒；本波出怪结束后等待 2 秒即开始下一波，不等待场上怪物清空。
- 普通怪物每波随机挑选 5 种均匀分配；第 20/40/60/80 波起，怪物池分别加入碉堡、气球兵、风眼首领、冻结者。
- 第 103 波起每 3 波出现 1 个坦克 Boss，占用本波 50 只中的 1 个名额；其它怪物不自动设为 Boss。
- 怪物每 2 波提升 1 级，等级为 `1 + floor((波数 - 1) / 2)`；召唤物保留原有机制并归属召唤者所在波。
- 一波出怪完毕且该波怪物、召唤物全部离场才计入击退波数；允许非致命漏怪，导致失败的波不计入。子弹不影响计数；没有波次回血奖励。
- 正常挑战结束后结算：金币 = 击退波数 x50；每 20 波折算 1 个普通宝箱单位，每 2 普通 -> 1 稀有、2 稀有 -> 1 史诗、2 史诗 -> 1 传奇。中途主动退出不发奖励，也不提交排行榜成绩。
- 例：192 波 = 9600 金币、1 传奇 + 1 普通；220 波 = 11000 金币、1 传奇 + 1 稀有 + 1 普通。
- 宝箱仍需正常解锁；库存上限 20，优先发放高品质，超出部分不发放并在结算中说明。新对局不保留上一局阳光、植物或波次。

### 排行榜

- 通关榜按已通关的不同主线关卡数排名，不按难度重复计数；金币榜按账号当前金币余额排名。这两个榜不按周清零。
- 无尽模式榜保留每位玩家本周最高通关波数，只有更高成绩才覆盖；同波数时更早达到该成绩者优先，时间也相同时按玩家 ID 排序。
- 无尽榜周期为北京时间周日 00:00 至下周日 00:00。对局跨周时，以服务端正式结算时的周期归属成绩；重试已经结算的旧对局不会把旧成绩写入新一周。
- 周冠军奖励 20000 金币 + 100 经验，发奖后清空本周成绩；无人上榜时不发冠军奖励。
- 定时任务按 UTC 周六 16:00 调度，并在访问排行榜、读取账号存档和获取通知时检查补结算。冠军通知确认后删除，不重复显示。
- 每个玩家仅保存一条当前周成绩，不累计历史周明细。账号注销同步删除无尽榜成绩。

### 每日商店

- 每位玩家独立随机生成每日商品，北京时间 00:00 刷新；当天刷新页面或重新登录不会重抽。
- 3 种不重复的植物碎片商品，每种 1–10 个，价格为数量 x500 金币；所有可升级植物等概率，南瓜头不进入碎片池，未解锁植物也可能出现。
- 1 种元素碎片商品，六种元素等概率，每种 1–4 个，价格为数量 x1 钻石。
- 每个商品每日只能购买一次；购买后碎片直接到账，不会直接解锁植物或元素。
- 商品、数量、价格与购买状态由服务端校验；跨日的旧商品订单不会扣款。数据库每位玩家仅保留当前日期的商品和 4 个购买标记，不累计每日购买历史。
